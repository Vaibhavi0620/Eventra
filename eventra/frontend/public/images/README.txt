Homepage hero: replace hero.jpg (landscape, dark, min 1920x1080) or run:
  cd backend && npm run event-image -- hero ./your-photo.jpg
Event photos are NOT stored here. Change them from the website (Organizer/Admin: open an event, 'Change photo')
or from the backend: npm run event-image -- set "<event name>" ./photo.jpg
Photos display in black & white and turn to colour on hover. Use only photos you have the rights to use.
